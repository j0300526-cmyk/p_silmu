# 한 손 조작

기본 hand_scheme은 one_hand다. 한 손의 손목 이동으로 팔을 움직이고 같은 손의
엄지·검지 pinch로 그리퍼를 닫거나 연다. 팔을 움직이기 위한 별도 pinch 클러치는 없다.
기존 양손 방식은 hand_scheme:=two_hand로 사용할 수 있다.

1. 카메라 창을 클릭하고 한 손 전체를 보여준다.
2. Space를 누르고 잠시 손을 고정해 현재 로봇 위치에서 기준점을 잡는다.
3. 손목을 움직여 팔을 조작하고, 엄지·검지 모으기/펴기로 그리퍼를 조작한다.
4. 손을 재배치하려면 Space로 정지한 뒤 재배치하고 다시 Space를 누른다.

P는 정밀 모드, Enter는 planned 목표 확정, Esc는 종료다.
그리퍼 제스처에도 짧은 dwell과 히스테리시스를 적용한다.
카메라 영상에 손 관절선을 표시하며, 아래쪽에 선택한 손과 마지막 그리퍼 명령을 표시한다.
이 표시는 실제 그리퍼의 힘이나 파지 성공 여부를 나타내는 값이 아니다.

control_hand:=auto는 오른손 또는 왼손 하나로 시작할 수 있으며, 둘 다 보이면 오른손을 선택한다.
선택 후에는 MediaPipe의 Left/Right 라벨을 고정한다. 선택한 손이 사라지거나 라벨이 바뀌거나
같은 라벨이 중복되면 다른 손으로 제어를 넘기지 않고 정지한다. 새로 Space로 활성화해야 한다.
이는 손의 Left/Right 분류를 이용하며 개인 신원이나 영구적인 손 ID 추적은 아니다.
피드백이 오래되거나 카메라 영상이 끊겨도 비활성화하고 재활성화를 요구한다.

팔 위치는 손목과 손바닥 기준점(0, 9), 그리퍼는 손끝(4, 8)의 거리로 계산한다.
따라서 손끝만 움직이고 손목·손바닥 기준점을 그대로 유지하면 팔 목표는 변하지 않는다.
실제 손을 오므리며 손목을 함께 움직이거나 가림으로 추정점이 흔들리는 경우까지
완전히 분리된다는 보장은 없다. 깊이는 단안 영상의 손 크기로 추정한다.

이 인터페이스는 [AnyTeleop](https://yzqin.github.io/anyteleop/)의 손목/손가락 역할 분리 원리를
OMX-F의 위치 제어와 2지 그리퍼에 맞게 단순화한 설계다. 논문의 전체 구현이나 성능 재현은 아니다.
물체 인식·목표 추론·자동 정렬 등의 shared autonomy 기능은 추가하지 않았다.

~~~bash
# 기본 한 손 방식
bash scripts/run_hand_control.sh

# 왼손만 허용
bash scripts/run_hand_control.sh control_hand:=left

# 기존 양손 방식
bash scripts/run_hand_control.sh hand_scheme:=two_hand
~~~

tests/test_hand_input.py는 단일 손의 팔/그리퍼 동시 조작, 손끝 동작 시 목표 유지,
손 교대 방지, 손 유실/피드백 유실 정지, 재활성화 시 기준점 재설정,
분류 중복 거부와 기존 양손 클러치 동작을 검사한다.
